# DATE2026-GNN4LSD Dataset

This repository provides four non-Manhattan layout datasets used in the paper:

**"(DATE 2026) Lithography Hotspot Detection for Complex Non-Manhattan Layouts via Graph Neural Network"**

Layers 4158/0 and 4159/0 are hotspot marker layers generated by Calibre.  
Layer 4158/0 contains pinch hotspot markers, and layer 4159/0 contains bridge hotspot markers.
